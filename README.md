**NOTE: You must download python3-tk for the game to work:**

- Python3-tk is the standard Python interface to the Tcl/Tk GUI toolkit.

- Run these commands in your debian-based OS:

```Lib
sudo apt update -y

sudo apt install python3-tk
```
